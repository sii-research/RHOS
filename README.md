# RHOS

## 🏛️ About RHOS Lab

RHOS studies Embodied AI, Physical Reasoning, and Human Activity Understanding.
We are building a knowledge and reasoning-driven system that enables
intelligent agents and robots to perceive human activities, reason about human
behavior logics, learn skills from human activities, and interact with the
environment.

**Our homepage**: [https://mvig-rhos.com](https://mvig-rhos.com)
